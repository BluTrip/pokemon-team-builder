OFFLINE POKÉMON TEAM BUILDER — iOS EDITION

INSTALL ON IPHONE / IPAD
1. Put this folder on a static HTTPS host (for example, a private GitHub Pages site), or serve it from a computer on your network for initial setup.
2. Open the hosted page in Safari on your iPhone/iPad.
3. Tap Share → Add to Home Screen.
4. Enable “Open as Web App” if iOS shows that option, then tap Add.
5. Open the new Home Screen icon once while online. The service worker caches the app files.
6. After that first successful load, the team builder can open offline.

IMPORTANT iOS LIMITATION
iOS does not reliably install a service-worker-based offline web app by opening index.html directly from the Files app. It needs to be served from HTTPS (or localhost) once so Safari can install/cache it. This ZIP is the complete app package, but it is not a signed native .ipa and cannot be installed through the App Store.

FEATURES
- Up to six Pokémon per team
- Moves, abilities, items, EVs, IVs, natures, Tera types, level, gender, shiny
- Showdown-style text import/export
- Local browser storage
