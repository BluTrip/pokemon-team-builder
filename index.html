Quick notes

This is a standalone offline team editor, not a battle simulator. Pokémon, move, item, and ability fields accept free text so it can handle custom formats, future releases, and unusual sets without needing an online database.

EVs are ordered HP / Atk / Def / SpA / SpD / Spe (maximum 510 total; maximum 252 per stat). IVs default to 31. Set level, nature, gender, shiny status, and Tera type as needed.

Saved teams stay in this browser's local storage. Use Export and keep a text backup if you want to move teams between devices or browsers.
